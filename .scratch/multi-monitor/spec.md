# 選擇目標螢幕並各自顯示完整桌布

Status: planned
日期：2026-10-29
需求來源：使用者指定多螢幕為必要完整性功能，並收斂為「可以設定在哪些螢幕上套用，有套用的螢幕都顯示一份完整的桌布」。

## 已指定的功能範圍

- 設定介面列出目前連接的螢幕，可勾選一個或多個套用目標。
- 每個勾選螢幕各顯示一份完整的目前主題，依該螢幕的顯示區域排版。
- 所有目標沿用同一個全域主題；未勾選螢幕不附掛動態桌布，保留 Windows 原桌布。
- 不提供跨螢幕拼接／延展成一張大畫布，也不增加逐螢幕不同主題的設定。
- 保存套用目標，重新啟動後恢復。原有全域網路與管理命令的安全邊界繼續有效。

## 必要生命週期與驗收方向

- 勾選／取消目標後，只在指定螢幕顯示；每個目標都應能獨立看到完整桌布，而非大畫布的一段。
- 正確處理各螢幕的位置、解析度／DPI、主螢幕變更及連接／移除，不把畫面誤套到未選螢幕。
- Explorer 重啟後恢復已選目標；桌面圖示、工作列與原有管理入口仍可操作。
- 暫停、繼續與正式退出能涵蓋所有目標，已觀察的相關子程序須正常清理。
- 螢幕辨識、首次預設與斷線重連等細節於實作前調查並具體化；設定視窗固定版面不取消各桌布目標的尺寸處理。

## 目前狀態

本文件記錄本輪已指定的呈現方式與範圍，尚未開始產品實作。沿用專案 TDD 與 Win32／WebView2 原生驗證邊界；實作前補齊技術規劃與具體案例。

產品／GUI／多螢幕驗證：NOT RUN（本次僅需求整理）。不操作或替換原持續桌布，不合併 main。
