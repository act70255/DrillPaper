## 需求與目前狀態

使用者希望以 Windows 工作列右下角的小圖示作為管理入口。現有程式只有 Preview 的原生主題選單與 CLI；尚無系統匣、獨立管理／設定視窗、圖形化匯入／移除與設定保存。原 handoff 已列 SystemTray 與最小管理介面，本文件具體化其互動，確認後才實作。

## 系統匣入口

- 使用可辨識的 DrillPaper 圖示，提示文字顯示目前主題與執行狀態。
- 單擊或雙擊開啟同一個管理視窗；重複操作只帶回既有視窗，不重建採集或 renderer。
- 右鍵選單：開啟管理介面、選擇主題、暫停／繼續桌布、桌布／預覽模式、設定、開啟日誌資料夾、結束。
- 暫停表示隱藏動態桌布、回到原桌面，並停止非必要更新；繼續後立即恢復新快照。暫停狀態僅限目前工作階段。
- Explorer 重啟後恢復系統匣圖示及目前模式；必要時有界等待通知區域就緒，不新增重複圖示。
- 圖示建立失敗時保留可操作的管理視窗與錯誤提示，不讓程式躲在背景卻沒有入口。Windows 自行決定圖示位於通知區或溢出區，不修改使用者的工作列設定。

## 管理視窗

### 主題

- 列出 Minimal、Dashboard 與已安裝主題，顯示名稱、版本與目前選擇。
- 可預覽、套用為桌布，以及透過檔案選擇器匯入 `.dmt`。
- 可移除使用者安裝的主題，需明確確認；使用中的主題先切換至內建主題，避免刪除仍使用的資產。內建主題不提供移除。
- 繼續使用原生 ThemeManager 的驗證、配額、staging 與原子安裝；介面不得繞過其安全邊界。

### 設定

- 顯示模式：桌布／預覽；主題與顯示選擇可保存。
- 智慧休眠：預設啟用，實際接入既有 runtime 政策，與手動暫停狀態分開。
- 主題網路：單一全域 HTTP／HTTPS 開關，預設封鎖。首次遭封鎖時提示前往設定，提示不會自動允許。延續已確認政策，其他 URI scheme 維持封鎖。
- 非敏感設定保存於 `%LOCALAPPDATA%\DrillPaper\settings.json`，採版本化驗證與原子寫入。LOCALAPPDATA 缺失或設定損毀時提供友善錯誤與日誌；不靜默改用任意目錄或覆蓋損毀設定。
- 設定提供套用／取消；成功套用才顯示已儲存，失敗保留可理解的目前有效狀態。驗收 CLI 參數的暫時覆寫不直接寫回偏好。

### 狀態與關閉

- 顯示目前模式、主題、運作／暫停／重新連線狀態與最近錯誤，提供日誌入口。
- 關閉管理視窗只隱藏管理介面，桌布與系統匣繼續運作；正式退出透過「結束」。管理視窗開啟時可正常出現在工作列與 Alt+Tab。
- 獨立 `--preview` 的關閉驗收語意仍明確保留，避免測試程序無法正常退出。
- 結束須停止採集、移除系統匣圖示、關閉 WebView2 與通知視窗，確認已觀察子程序退出。

## 模組與驗證邊界

- 維持 C++20／Win32／WebView2；管理視窗由可信原生 UI 提供，不讓第三方主題操作管理命令或設定檔。
- 公開 AppSettings／SettingsStore 契約：驗證保存、讀取、schema、缺失／損毀設定與寫入失敗；不以檔案測試宣稱 UI 通過。
- 公開 runtime 管理命令與有效狀態：驗證手動暫停、智慧休眠、模式選擇及互相覆寫的優先順序。
- ThemeManager 公開契約：延用匯入／列舉／切換與新增移除的邊界測試。
- 系統匣、管理視窗、檔案選擇器與 Explorer 復原用 Windows 整合／人工驗收；包括唯一入口、圖示恢復、關閉不退出、正式退出與焦點行為。
- 網路開關必須接入實際 host 政策並以真實 WebView2 請求驗證；配合完成 CSP、導覽、來源、下載、權限與彈窗邊界。不能提供只有外觀的可用開關，不能以 policy 單元測試宣稱沙箱。
