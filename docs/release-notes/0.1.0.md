# DrillPaper 0.1.0（Pre-release）

DrillPaper 的第一個預先發布版：把即時系統資訊（CPU、記憶體、磁碟、網路、時間、可用時的 GPU）顯示在 Windows 桌布上。

> **本版沒有程式碼簽章。** 安裝檔與 `DrillPaper.exe` 都未經 Authenticode 簽章，Windows SmartScreen 或企業防毒可能警告或攔截。請核對下方 `SHA256SUMS.txt` 的雜湊值；企業環境請向 IT 申請針對該檔案與 hash 的例外，不要自行停用防毒。

## 下載

| 檔案 | 說明 |
| --- | --- |
| `DrillPaper-0.1.0-Setup.exe` | 安裝檔：只安裝給目前使用者（`%LOCALAPPDATA%\Programs\DrillPaper`），不需要管理員權限，可從「設定 → 應用程式」解除安裝 |
| `DrillPaper-0.1.0-win-x64.zip` | 免安裝版：解壓後執行 `Start-DrillPaper.cmd` |
| `*.json` | 套件 metadata（來源 commit、逐檔 SHA-256、版本） |
| `SHA256SUMS.txt` | 所有檔案的 SHA-256 |

核對雜湊（PowerShell）：`Get-FileHash .\DrillPaper-0.1.0-Setup.exe`，與 `SHA256SUMS.txt` 比對。

## 系統需求

- Windows 10／11 x64。
- Microsoft Edge WebView2 Runtime（Evergreen），Windows 11 大多已內建；缺少時安裝程式與啟動入口會提示下載網址。
- 不需要 VC++ 可轉散發套件、Node、Python 或 Visual Studio。

## 主要功能

- 兩個內建主題（Minimal、Dashboard），每個選取的螢幕各自顯示完整主題，未選螢幕保留 Windows 桌布；支援混合 DPI、螢幕拔插與全部離線時暫用主螢幕。
- 固定 800×600 的管理視窗，可選主題、桌布／Preview 模式、目標螢幕與主題網路；系統匣可重開、暫停／繼續與正式結束。
- 智慧休眠：鎖定、關螢幕、前景全螢幕時暫停更新以省電，恢復後自動繼續；JS 無回應時有界復原。
- 匯入、切換、移除第三方主題（`.dmt`）；附 TypeScript 主題作者範本與 SDK。主題網路預設關閉。
- 沒有遙測；WebView2 的 SmartScreen 信譽檢查已關閉。

## 安裝、更新與移除

- 安裝檔覆蓋安裝時，會先正式結束執行中的 DrillPaper 再替換檔案；以 Preview 模式開啟的視窗需先手動關閉。
- 解除安裝最後會詢問「要保留 DrillPaper 的使用者資料嗎？」，預設保留；使用者資料在 `%LOCALAPPDATA%\DrillPaper`。

## 驗證範圍

- 自動：Release 建置與原生測試、SDK 與封裝契約測試；本版檔案由 GitHub Actions 依 tag 從同一 commit 建置、驗證白名單與 hash 後發布。
- 實機（Windows 11 25H2、WebView2 156、Intel 內顯、雙 1920×1080 DPI 144／96）：雙螢幕套用、桌面互動、真實鎖定／解鎖 5 次、實體拔插、Explorer 重啟、介面匯入主題、100 次主題切換與約 52 分鐘雙螢幕長測、安裝與解除安裝。

## 已知限制

- 沒有程式碼簽章。
- 單一螢幕被全螢幕程式覆蓋時，所有螢幕一起暫停並暫時顯示 Windows 原桌布。
- 主題內容沒有沙箱化，只匯入你信任的主題；WebView2 元件仍可能有自身背景流量（例如 WPAD），不宣稱整個程式零外連。
- 只在單一 Windows 11 環境驗證；其他 Windows／WebView2 版本、NVIDIA GPU、乾淨使用者環境、待機／喚醒等尚未驗證。長測只有約 52 分鐘，不宣稱沒有記憶體洩漏。
- 管理日誌沒有時間戳記；手動暫停時標題顯示「display-off」。
