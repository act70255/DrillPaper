# Triage Labels

工程技能使用五種標準 triage 角色。本表將這些角色對應至本專案 issue tracker 使用的 label。

| mattpocock/skills 中的角色 | 本專案使用的 label | 意義 |
| -------------------------- | ------------------ | ---- |
| `needs-triage`             | `needs-triage`     | 維護者需要評估此 issue |
| `needs-info`               | `needs-info`       | 等待回報者提供更多資訊 |
| `ready-for-agent`          | `ready-for-agent`  | 規格完整，可交由 agent 處理 |
| `ready-for-human`          | `ready-for-human`  | 需要由人員實作 |
| `wontfix`                  | `wontfix`          | 不會處理此項目 |

技能提到某個角色時（例如「套用 AFK-ready triage label」），請使用本表對應的 label 字串。

若本專案實際使用不同名稱，請修改「本專案使用的 label」欄。
