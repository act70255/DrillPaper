# RC 13 人工清單

以下均 **NOT RUN**：本票自動化取得 HWND／文字／檔案與握手證據，沒有人工操作或目視回報，不將其當成人眼可讀性驗收。其他 Windows／Runtime／DPI 與實體熱插拔也未執行。

請使用本票來源的隔離 EXE 與獨立 LOCALAPPDATA，位於非 Temp 使用者目錄，由 CMD 或直接執行啟動。保留 PID 83428 原桌布，不重啟 Explorer；若防毒攔截，記下 Apex One 產品／規則／時間／項目並標 BLOCKED，不修改防毒。

1. 在桌布模式取消所有螢幕勾選，分別按「套用並儲存設定」及主題「套用」。確認訊息框及管理狀態清楚顯示「桌布模式至少需選擇一個目標螢幕。」；原桌布目標不變。
2. 保持空選擇按主題「預覽」，再選 Preview 模式保存設定、退出並重啟。確認單一預覽視窗與設定保留；按切回桌布應顯示上述提示，預覽仍存在。勾選一屏再套用應成功。
   另以保存空 Preview 的隔離資料執行 `--experimental-desktop`，確認顯示具體提示並退出，原設定不變；需要設定時用 `--management --preview` 重新開啟。
3. 在 100%／150% 與其他實際縮放逐屏檢查固定 800×600 邏輯用戶區、長訊息捲動／複製、按鈕與鍵盤可達性；確認文字不截斷、繁中可辨識。自動化原生幾何測試只建立相應 API 證據。
4. 其他 Windows／WebView2 Runtime 若需宣告支援，使用相同來源重做上述流程並記錄版本、hash 與結果。
