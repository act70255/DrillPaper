# 08／09 交付人工清單

以下均 NOT RUN：目前是有來源樹、建置工具與 Apex One 的開發帳號；自動隔離測試不等於乾淨一般使用者機器。依確認決策不因此中斷 08，但仍為 09 的驗收 gate。記錄每項日期、操作者、來源 commit、EXE／ZIP hash、Windows build、Runtime、權限、螢幕／DPI、防毒產品／版本、結果與證據。

1. 在另一台無來源樹、Visual Studio、Node、Python 的 Windows 一般使用者機器，從可信管道取得 ZIP 與獨立 SHA-256。解壓到非 Temp、含空白與繁中的使用者路徑，確認檔案清單，雙擊 CMD。不得以系統管理員身分執行 app；不修改防毒。
2. 分別準備有／無／過舊 VC++ x64 Runtime、WebView2 Evergreen 的乾淨映像；不在現用主機解除安裝依賴。缺依賴時應有繁中提示／官方取得方式，無自動安裝／提升權限；備妥後重新執行。直接 EXE 缺 CRT 的 Windows loader 訊息不算入口友善提示通過。
3. 每次防毒介入記錄時間（含時區）、產品／完整版本、規則、目標 hash、啟動方式與受影響步驟，該項 BLOCKED，另向 IT 申請例外並附來源 hash；不要把攔截當產品 FAIL、忽略警告或自行停用防毒。沒有完整可讀日誌時記「觀測不足」，不能聲稱無攔截。
4. 全新資料首次啟動應為 Minimal／唯一主螢幕桌布、智慧休眠開啟、主題網路關閉；查看兩個內建主題完整版面、實際數值／不可用狀態與連續更新。圖示／工作列／Alt+Tab／Win+D／焦點／虛擬桌面及實際系統匣點擊另逐項記錄。不得用握手、JS callback 或 HWND 樣式取代畫面與互動驗收。
5. 透過 GUI 選檔匯入可信 DMT，確認列表／載入；取消與確認移除，再匯入同版本。保存主題／模式／目標／網路偏好，取消草稿，正常退出並從相同 CMD 重啟；核對保留設定、Preview 模式及唯一管理視窗。CLI 匯入及 ThemeManager 移除契約測試不代表 GUI 選檔與確認對話框 PASS。
6. 混合 DPI／不同解析度、多目標、部分及全部離線、恢復連線、clone 配置逐項驗證。每個選中螢幕應完整顯示相同主題，未選螢幕維持 Windows 桌布；離線選擇保留，全部離線暫用主屏、不寫回設定。
7. 另約人工時段驗新版真正 Explorer 重啟、鎖定／關屏／待機／喚醒、全螢幕及部分覆蓋與故障交錯。此票未授權重啟 Explorer 或關閉／替換原持續桌布；執行這些步驟前須另獲授權並使用專用環境。
8. 在專用環境按交付 README 備份資料、解壓新版本到新目錄、退出舊版後啟動新版；驗替換及回復舊版／資料備份。正常退出後移除整個解壓目錄，確認 app／已觀察 WebView2 程序已退出、資料仍保留。由使用者主動選擇清除該專用資料，核對不影響其他帳號／資料；沒有安裝器，不能宣稱安裝器／解除安裝驗證通過。
