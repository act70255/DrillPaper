# RC 12 人工驗收清單

以下皆 **NOT RUN**，因本機未取得真正無法辨識的顯示器，且需人工改變顯示配置／觀看畫面；不以 API fixture、HWND 或 WebView2 握手代替。

前置：由 James 安排獨立測試機／受測程序，記錄產品 EXE SHA-256、Windows／Runtime／螢幕解析度／DPI、穩定 ID 與保存設定。使用非 Temp 的使用者目錄、全新 LOCALAPPDATA，透過 CMD 或 Node 啟動。保留目前持續桌布；本輪未授權重啟 Explorer 或替換 PID 83428。

1. **真正無法辨識的顯示器**：以驅動／轉接器可重現的識別讀取失敗配置，先保存單屏，再使另一屏無法辨識。確認所有連接螢幕各完整顯示同一 Minimal／Dashboard，沒有跨屏拼接；管理介面顯示指定退化提示。記錄原生錯誤碼／日誌，不猜測裝置 ID。
2. **清單與保存**：無法辨識列顯示「無法辨識」，滑鼠及空白鍵不能勾選；詳細區說明不能保存。原已選裝置若失去識別，原穩定 ID 仍作為未連接項目保留。按保存、取消、重啟，核對 JSON 只含合法穩定 ID，沒有區域鍵或空 ID；首次無可辨識主屏時不能保存空目標。
3. **恢復與拔插**：全部恢復辨識後，確認自動只套回保存目標、提示移除且設定未被自動覆寫。逐一驗部分斷線、全斷線暫用主屏、接回、更換主屏與負座標。
4. **clone／混合 DPI**：實體鏡像及混合辨識狀態下，每個桌面區域僅一宿主；不同解析度、100%／150% 以外的 DPI 與橫直向配置，完整主題無裁切，沒有錯誤跨屏縮放。
5. **真正整體列舉失敗**：可重現 QueryDisplayConfig 失敗時，分別從已有成功結果及首次啟動驗證。前者保留成功拓樸、持續採樣／渲染健康檢查與宿主復原；後者暫用主屏並提示。錯誤詳情進本機日誌，恢復後自動重試成功。
6. **Preview／人工畫面**：上述故障中以獨立 Preview 與含管理介面的 Preview 啟動、切題與維持更新，確認仍可使用。人工核對桌面圖示／工作列／焦點／Alt+Tab；不因本清單而重啟 Explorer。
7. **環境矩陣**：另一 Windows／Runtime／驅動及乾淨一般使用者環境重驗；本機 Windows 11 的 API 注入結果不外推。

遇防毒攔截：記錄 Apex One 產品版本、規則、時間、程序及受影響情境，標 **BLOCKED**；不修改防毒設定，不把未知產品失敗直接歸因防毒。完整套件留收尾，其他 RC gate／票 10、11 的缺陷與證據缺口持續保留。
