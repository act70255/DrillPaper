# 固定設定視窗需求與驗證

票據：`.scratch/rc-delivery/issues/02-fixed-settings-window.md`（已確認）。基準 `0c97d4fdda3881a3d11bc7f93d7fc12829749f56`，分支 `feature/rc-02-fixed-settings-window`。

## 實作規劃

- 管理視窗的用戶區固定為 800×600 DIP（96 DPI），邊框另計；依目前螢幕 DPI 換算實體像素，跨螢幕時重新計算。禁止最大化與拖曳邊框調整大小，不新增使用者縮放設定。
- 頂部為可捲動、唯讀且可複製的狀態文字及暫停／模式操作；中間左右欄為主題與螢幕清單；下方保留模式、智慧休眠、網路與保存／取消／退出。
- 螢幕清單可垂直捲動，選取列的完整名稱與穩定識別顯示於可捲動的唯讀詳細區；不改保存 ID。長主題名稱可水平捲動。
- Tab 按閱讀與操作順序移動，Shift+Tab 反向；初次開啟提供焦點並顯示鍵盤焦點提示，空白鍵沿用原生按鈕與勾選行為。關閉仍隱藏唯一視窗；取消及保存沿用既有 composition／SettingsStore。
- 工作區小於完整視窗時，不縮小或裁掉固定版面；文件提供 Alt+Space、M 與方向鍵移動視窗，Tab／Shift+Tab 操作所有控制項的方式。
- 不修改主題、網路、匯入／移除或原子保存政策；不重啟 Explorer、不操作原持續桌布。

## 已確認 seam 與相關驗證

- Windows 原生整合：實際建立 ManagementShell，GetClientRect 比對規格，移至可用 100%／150% 螢幕後核對實體尺寸、控制項邊界、固定尺寸、清單捲動及草稿。先取得一個尺寸失敗測試，再做最小實作；單元測試不代替 GUI。
- AppSettings／SettingsStore：沿用既有相關測試與管理／多螢幕程序整合，確認取消／保存／重開／重啟，原子與網路政策不變。
- 截圖與人工操作分開記錄；無法執行的人工項目標示 NOT RUN，附清單。完整套件留 09 收尾。

## 人工清單

使用隔離資料及受測版本，勿操作原持續桌布。

1. 100% 與 150%：檢查文字、清單、長繁中錯誤與底部操作可見；跨屏後仍為 800×600 邏輯用戶區，最大化與拖曳不改版面。
2. Tab／Shift+Tab 走完全部控制項，觀察可見焦點；空白鍵勾選螢幕／智慧休眠，按鈕可以鍵盤觸發。
3. 變更主題／目標／模式／網路草稿，取消後恢復；保存後關閉／重開及正式退出／重啟一致。
4. 匯入檔案選擇器取消與成功、移除確認取消與確認；錯誤文字可捲動讀完整，長裝置 ID 可複製。
5. 重複系統匣開啟仍只有同一視窗；視窗關閉只隱藏，正式退出清理本次測試程序。
6. 小工作區用 Alt+Space、M 與方向鍵移動視窗；Tab／Shift+Tab 可到達底部操作。此方式不改固定尺寸或 Windows 縮放。
