# 剩餘 MVP 實作需求

日期：2026-10-28。依已確認的 `DesktopMonitor_Codex_Handoff.md` 與使用者「繼續補完剩下的部分」執行；不擴充商城、雲端或原生外掛。

## 交付順序與驗收

1. 恢復 Windows x64 可重現建置，先完成原生主題管理：manifest、資料夾與 `.dmt` ZIP 驗證、限額、安全 staging 與原子安裝、列舉、選擇、失敗回復。已安裝版本使用不可變目錄，拒絕覆蓋同版本。
2. 在同一個 WebView2 controller 熱切換主題；以原生功能表提供選擇、匯入與網路設定。載入失敗或逾時回到可用的內建主題。
3. 將採集移到可停止的背景執行緒；UI 只取有界 mailbox 最新值。接入工作階段、顯示器電源與全螢幕政策，恢復時立即採樣、顯示並送出完整快照。
4. 網路預設禁止；首次遭封鎖提示前往設定，只有全域 HTTP/HTTPS 開關可放行外部資源。導覽、訊息來源、權限、下載、彈窗仍分別限制；以真實 WebView2 負面案例驗證，不以模型測試宣稱沙箱。
5. 驗證桌布附掛／Preview fallback、renderer recovery、內建主題與 100 次切換；缺少可視操作或另一版 Windows 時，具體記為 NOT RUN。
6. 完整回歸、10 分鐘以上程序樹效能、可攜套件內容與解壓啟動檢查，更新 README、架構、STATUS、FINAL_HANDOFF。真正 RC 仍須通過安全、相容性與乾淨使用者驗收；不以原始碼檔案存在當作發行 gate。

## 已確認的公開測試邊界

- Theme manifest／封裝與安裝：驗證可觀察的檔案、清單與拒絕行為，不能證明瀏覽器安全。
- Runtime 狀態與有界 mailbox：驗證停止、恢復與最新值，不取代實際 Windows 電源事件。
- Protocol／SDK：驗證資料契約與來源；畫面與請求攔截另做 Windows 整合檢查。
- Win32 Shell／WebView2：實際 Windows 程序、事件與可視檢查，單元測試不算 GUI 驗收。

每個可測行為先執行一個失敗測試再完成最小實作。使用各功能分支與繁體中文 Conventional Commits。外部依賴鎖定版本、附授權；基本執行不需管理員權限、不送遙測。
